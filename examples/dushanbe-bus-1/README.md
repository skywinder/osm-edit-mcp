# Душанбе · автобус № 1 от улицы Гагарина до Южного терминала

23 ноября 2026 года картограф iuvi подтвердил порядок пяти остановок на пробном участке и сообщил, что автобус едет прямо к рынку Саховат. MCP сопоставил этот участок длиной около 1,6 км с дорогами и платформами OpenStreetMap. Для остальных участков направления ещё нужны сведения о пути автобуса.

| Слой | Что показывает |
| --- | --- |
| [Университет → рынок Саховат](dushanbe-bus-1-example.geojson) | По ходу движения идут Коммерческий и Технологический университет, 43 Микрорайон, 45 Микрорайон, ТЦ Ганджина и Рынок Саховат. Линия использует геометрию дорог OSM. Маркеры показывают соответствующие нанесённые платформы. |
| [Дороги у рынка Саховат](sahovat-road-options.geojson) | Прямой проезд по проспекту Негмата Карабаева согласуется с сообщением картографа. На карте также виден расчётный объезд по боковой дороге с возвращением к платформе с юга. В пробный путь вошёл прямой вариант. |
| [Гагарина, Южный терминал и Ресторан Океан](dushanbe-bus-1-stops.geojson) | Объекты OSM для дальнейшей сверки. Требуется определить платформу отправления у Гагарина и платформу прибытия у терминала. |

### Три пропуска в черновике

Картограф попросил пропустить три остановки при подготовке этого направления. MCP проверил карту 23 ноября 2026 года. В пределах 50 м от каждого из трёх присланных ориентиров поиск автобусных платформ и точек остановки дал пустой результат.

| Ориентир картографа | Что нашлось при расширении поиска до 150 м |
| --- | --- |
| Госфилармония | Одна [безымянная автобусная платформа](https://www.openstreetmap.org/node/301733916) в 111 м. Её связь с Госфилармонией и маршрутом № 1 остаётся открытым вопросом. |
| Поворот на посёлок «Кахрамон» | Данные OSM не содержат подходящей остановки в этом радиусе. |
| Посёлок «Чимтеппа» | Данные OSM не содержат подходящей остановки в этом радиусе. |

Проверка также охватила нанесённые площадки и отношения остановок в окрестности каждого ориентира. Для всех трёх пропусков в черновике можно указать название и причину. Привязка пропуска к конкретному объекту OSM потребует отдельного подтверждения. Текущее положение и обслуживание этих остановок можно уточнить по поездке.

Для просмотра скачайте GeoJSON кнопкой **Download raw file**, откройте iD и перетащите файл на карту. При необходимости откройте **Данные карты → Пользовательские данные** и приблизьте карту к слою. [Открыть iD на пробном участке](https://www.openstreetmap.org/edit?editor=id#map=16/38.52460/68.76170)

Для сборки полного направления пригодится трек поездки либо перечень улиц и поворотов от Гагарина до начала пробного участка и от рынка до Южного терминала. Обратный рейс можно проверить по его собственному треку и остановкам.
